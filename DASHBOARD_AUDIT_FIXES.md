## Formulas

- **Annual maxima:** `M(y) = max(training_FLOP_i)` among eligible frontier models published in year `y`; `H(y) = max(tensor_FP16_BF16_FLOP_per_second_j)` among hardware released in `y`. Only positive finite observations enter. These are annual, not cumulative maxima.
- **Indexed comparison:** `I_model(y) = M(y) / M(b)` and `I_chip(y) = H(y) / H(b)`. The common base `b` is 2016 if valid in both series, otherwise the earliest shared year. Here `b = 2017`, `M(b) = 8.43e20 FLOP` (JFT), `H(b) = 1.25e14 FLOP/s` (tied hardware records; first retained winner is NVIDIA Tesla V100 SXM2). Each ratio is dimensionless; both equal 1 at the base. Display filtering does not change denominators. No observations are fabricated for missing years; the model series ends in 2025 and hardware in 2026.
- **Cluster scale:** `count_i = Hardware quantity_i`, only if a positive integer, dated, explicitly frontier, with a recognized accelerator hardware name (NVIDIA, Google TPU, Huawei Ascend) or explicit GPU wording in the data-center field. Quantity is never inferred from FLOP. `FLOP / (FLOP/s)` has units of seconds and is not a chip count. The conservative name checks omit unknown units, including CPU-core and machine counts found in this file.
- **Weight shares:** `share(category) = 100 * n(category) / N` for the selected population; Unknown is included in `N`. With `N = 0`, displayed counts and shares are zero and a no-data message is shown. The full-snapshot missing-coverage note uses the full snapshot as its denominator.
- **Costs:** `C(y) = max(Training compute cost (2023 USD))` among dated, positive, selected records and the selected confidence mode. Values are imported, not recomputed. No projection is drawn.
- **Launch prices:** `P(manufacturer,y) = max(Release price (USD))` among eligible releases, followed by ranking manufacturers by their maximum `P` and retaining six. Price is nominal USD. Connecting lines include gaps and imply no inserted observations.
- **Hardware record curve:** for each group (NVIDIA, Google, remaining suppliers), `R(t) = max(tensor throughput)` among selected releases at or before `t`. It starts at the first eligible record within the selected window. No claim about total chip supply follows.
- **Organization maxima/counts:** maximum training FLOP per recorded organization string; top 15 sorted descending. Treemap area is proportional to model-record count by country group and organization string. Frontier participation is the cardinality of unique non-missing organization strings per publication year. Joint organization strings remain one recorded group.
- **Annual output/KPIs:** count eligible rows by year/primary domain or selected dates. Primary domain is the first recognized domain token, otherwise Unknown. Counts do not weight confidence or deduplicate shared training runs.
- **Compute trend:** ordinary least squares `log10(FLOP) = a + b*t`, where `t` is elapsed time in 365-day years from 2012-01-01. `b = sum((t-mean(t))*(logF-mean(logF))) / sum((t-mean(t))^2)`; `a = mean(logF)-b*mean(t)`. Skip degenerate fits. Draw only over displayed observations; no external growth number is attached to this fit.
- **Violin:** `x = log10(FLOP)`, Gaussian kernel density `f(x) = sum(phi((x-x_i)/h))/(n*h)`, `h = max(1.06*s*n^(-1/5), 0.15)`, where `s` is sample standard deviation. Width is divided by each domain's maximum density. Quartiles use linear interpolation at position `q*(n-1)` in sorted log-FLOP values. Domains need four observations.
- **Coverage:** minimum/maximum valid source dates separately by dataset, independent of display filters. A source date is not an update timestamp.

## Remaining Weaknesses

- Selected static exports, not comprehensive populations. Export/retrieval dates and upstream selection procedure are not documented; file timestamps are not treated as data provenance.
- Latest years are partial. A decline in annual publication counts, annual maximum throughput, or organization counts does not establish declining capability or organizations exiting the frontier.
- Counts include model versions that can share training runs. Joint organization names are not fully resolved into distinct institutions. Country of organization does not locate deployed compute.
- Source estimates contain uncertainty and sometimes ambiguous or incomplete notes. Model confidence is retained, but does not certify individual cost, stage, or quantity fields. Some accelerator observations refer to RL or mixed hardware.
- The quantity eligibility rule is deliberately conservative. Unspecified units are excluded even if a plausible accelerator count could be inferred. TPU cores/chips, accelerator packages, and GPU boards may not be equivalent units.
- Tensor throughput is peak FP16/BF16, with architecture and source-specification differences. It is not achieved training speed, utilization, energy efficiency, total installed capacity, or a complete supply measure.
- Listed prices are incomplete and not inflation-adjusted or necessarily comparable configurations. No reliable generational price-growth claim is made.
- Costs are final-run estimates. The AI Index Gemini estimate and the local Epoch amortized-cost field use different approaches; do not merge them. Cottier's conditional extrapolation is historical published context, not an updated prediction.
- Weight status remains substantially missing, including 46.0% of all supplied records. Availability does not measure capability or fully describe licensing.
- No direct evidence here supports market-share, university-exit, affordability, national-capacity, export-control-effect, or matched-quality inference-price conclusions.
- Runtime still requires the pinned PapaParse CDN asset; fonts are externally hosted. Raw CSV source notes are retained unchanged, including their original claims and typography. The site uses no em dashes in authored user-facing copy.

## Validation

The repository previously had no build, lint, or test commands. Added syntax, analytical-regression, browser-regression, and read-only source-profile checks.

- `npm run check`: passed JavaScript syntax validation.
- `npm test -- --browser`: passed source and synthetic-data regression tests plus local HTTP / Chromium checks. Both CSV requests returned HTTP 200. All five tabs rendered without JavaScript or console errors. Confidence, domain, hardware-type, organization, and date controls were exercised, including no-data and single-year windows, tooltips, About, methodology dialog, theme, and repeated navigation. SVG coordinates were checked for NaN/Infinity.
- Desktop 1440px and mobile 390px screenshots for every tab were inspected. Mobile navigation is reachable, page width does not overflow, and charts fit their cards without horizontal overflow; optional zoom and drag panning is available. Screenshot outputs are in ignored `artifacts/` and can be regenerated.
- `python scripts/profile_data.py`: read every source row and column, checked CSV width consistency, profiled types/missingness, and reproduced coverage. No raw data were changed.
- `git diff --check`: passed. Required bad-claim strings were searched across application and documentation. Remaining occurrences describe the audit history, negative test assertions, legitimate model names/years, or distinguish estimates from disclosures. Original raw source notes remain unchanged.

All requested acceptance items are satisfied in the active dashboard. The index uses 2017 rather than 2016 because the strict tensor-throughput field has no valid 2016 observations. There is no live FLOP/throughput cluster quotient and no dashboard forward-cost projection.
